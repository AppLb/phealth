# pHealth — phealth.space

Сайт собирается генератором [Eleventy](https://www.11ty.dev/) из файлов в `src/`.

## Как сайт попадает на hoster.kz

1. Изменения вливаются в ветку `main` (merge pull request).
2. GitHub Actions собирает сайт (около минуты, вкладка **Actions**) и кладёт готовые файлы в ветку `site`.
3. В Plesk нажать «Развернуть» — Plesk забирает ветку `site`.

Ветку `site` руками не трогать: её перезаписывает сборка.

## Где что лежит

| Что | Где |
|---|---|
| Меню, подвал, строка о запуске | `src/_data/site.js` |
| Шапка и подвал (разметка) | `src/_includes/partials/` |
| Общий каркас страницы | `src/_includes/layouts/base.njk` |
| Шаблон статьи | `src/_includes/layouts/article.njk` |
| Главная | `src/index.njk` |
| Статья про витамин D | `src/vitamin-d/index.md` |
| Заметки журнала на главной | `src/notes/*.md` |
| Цвета тем журнала | `src/_data/topics.json` |
| Общие стили и скрипты | `src/assets/` |

## Новая заметка журнала

Создать файл в `src/notes/`, например `src/notes/zheleso-i-chay.md`:

```markdown
---
title: "Почему железо не пьют с чаем"
date: 2026-11-20
topic: Добавки
---
Первый абзац.

Второй абзац.
```

`topic` — одна из тем в `src/_data/topics.json`. Заметка сама появится на главной, новые сверху.

## Новая статья

Создать папку с файлом `index.md`, например `src/omega-3/index.md`. Шапку (front matter) взять из `src/vitamin-d/index.md`. В тексте:

- `## Заголовок раздела`
- `{% ctx %}Пояснение под заголовком{% endctx %}`
- `{% claim 3 %}Утверждение с меткой.{% ref 2 %}{% endclaim %}` — метка 4 «Сильные», 3 «Умеренные», 2 «Ограниченные», 1 «Не подтверждено»
- `{% ref 2 %}` — сноска на второй источник из списка `sources`
- `{% note "Коротко." %}Текст врезки{% endnote %}`, спорное место: `{% note "Спорное место: …", "dispute" %}…{% endnote %}`

## Собрать у себя

```
npm install
npm start
```

Сайт откроется на http://localhost:8080 и будет обновляться при сохранении файлов.
